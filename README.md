# XCGF.Arena

## Structure

```
XCGF.Arena.slnx
src/XCGF.Arena/                 Class library
src/XCGF.Arena.Console/         Console host that runs the library
tests/XCGF.Arena.Tests/         xUnit tests
```

## Build, test and run

```bash
dotnet build
dotnet test
dotnet run --project src/XCGF.Arena.Console
```
